服務對象跨研發、行銷、採購、環安衛、財會、法務、智權、人資、品保等多元部門。

1. **雲端/Docker/K8s 零實證**：必備三連缺口，是最可能被刷的點。建議面試前補「本機 Docker 跑 mini-llm-agent」的最小實證，並誠實定位為「學習中」。
2. **碩士在學**：資格面需主動說明進度，避免被當不符合學歷。
3. **「3年 AI 相關經驗」薄弱**：用 MES IT 系統經驗 + LLM 專案補，但密度要能講清楚。
4. **部署成本/資安取捨**：無雲端語境，只能講 MES 地端權限/異常處理的類比，深度有限。
